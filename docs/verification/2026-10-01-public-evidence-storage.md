# Lossless public evidence storage

GitHub Actions retained 426 artifacts using about 2.43 GB on 2026-10-01. Most of the bytes were public market evidence. One normal daily artifact stored nine JSON files totaling 120,007,752 uncompressed bytes; six NFL availability bundles repeated three common source bodies across games. Its GitHub artifact occupied 18,308,215 bytes. A solid xz archive of those exact nine files occupied 2,824,948 bytes, with byte-for-byte restoration. This measures a concrete example, not a guaranteed saving for every run.

Both collection workflows still stage only allowlisted public JSON and reject configured credentials. Gitleaks still scans the uncompressed staged directory. Only after those checks pass, a standard-library packer validates paths, writes a deterministic tar.xz archive with a per-file SHA-256 manifest, and verifies every member before upload. Empty stages upload nothing. GitHub's artifact wrapper uses compression level zero around the already compressed tar.xz. Retention remains 90 days; no source bodies, provenance hashes or replay inputs are discarded. After downloading an artifact, extract `public-evidence.tar.xz` and run `python -m sportsbet.ingestion.pack_public_artifacts --help` for pack options; `verify(path)` checks the manifest before replay.

This changes storage only. It adds no provider request, model change, qualification change, reserve bypass, spending authorization or wager. Older GitHub artifacts are unchanged and need separate retention review. The held frontend release and frozen prospective audits are unchanged.
