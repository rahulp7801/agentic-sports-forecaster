# NBA empty opening-season refresh

The 2026-27 NBA regular season had no game-log rows on 2026-10-01. A free, read-only NBA.com `PlayerGameLogs` probe returned zero rows with all required schema fields present. The live daily worker previously treated this valid empty batch as `ValueError` because row and batch provenance hashes require at least one actual stat row. NBA refresh was marked failed and the scan was blocked.

Ingestion now records a zero-row, `empty` season coverage result without inserting a fabricated stat row or batch hash. Missing schema still fails. The daily pipeline can proceed to scan while source coverage explicitly says the new season has no rows; any pick still must pass the existing history, source, current-context, quote and qualification gates. No model, probability, threshold, provider quota, reserve or betting behavior changes.

Production follow-up: the merged empty-frame fix passed CI, but a no-key hosted refresh still raised `ValueError` about 34 seconds after starting the NBA.com request. NBA.com can surface a transport/body parsing failure as `ValueError` before a DataFrame exists. The source-call and `get_data_frames()` boundary now converts only those errors to `RequestException`, activating the existing seven-day ESPN/crosswalk fallback. The 2027 schedule, player and team crosswalk assets were confirmed present. Stat provenance failures and missing required columns remain hard failures; there is no empty-result substitution for an unavailable source.

A second no-key hosted refresh still failed. A local replay of the free 2027 ESPN crosswalk against mocked database reads found the precise fallback defect: the source's exact-match confidence is serialized as `1.0` for 1,255 schedule, 533 player and 30 team rows; the verifier accepted only the string `1`. It now accepts decimal spellings of exactly one with zero fractional digits, and still rejects every fuzzy, missing, unmatched, duplicate or season-mismatched identity. This is source-format compatibility, not a confidence threshold reduction.
